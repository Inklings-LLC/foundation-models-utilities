# foundation-models-utilities — repo orientation

Extra utilities for working with LLMs via Apple's Foundation Models
framework: custom skills, context-management helpers, and a chat-completions
client that connects to a hosted model of your choice. Cross-platform (Apple
platforms + select Linux). `skills/` teaches a coding agent how to use this
package.

  symlinked `AGENTS.md` (Codex) — same file, read once.

  as you learn repo-specific rules worth handing to the next session.
